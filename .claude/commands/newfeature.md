Invoke the `newfeature` skill and follow it.

Run the framing conversation first, then create `spec/<feature>.md` (a stub,
before building) and `decisions/<feature>.md` (origin + phase roadmap). Write
the spec stub even when the idea might be reverted. Does not write code and
does NOT commit.
